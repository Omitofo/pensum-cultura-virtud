# Responses — Logs vivos de intentos

Aquí se guardan los intentos de respuesta del alumno y las respuestas del Oráculo.

## Cómo usarlo

1. Elige una pregunta del pensum.
2. Crea (o usa) la carpeta correspondiente, por ejemplo:

```
responses/01-aprender-a-pensar/q01-opinion-creencia-hipotesis-conocimiento/
```

3. Dentro crea o edita `attempts.md`.
4. Escribe tu intento con el formato:

```markdown
### Intento 1 — YYYY-MM-DD
**Alumno:**
[tu respuesta]
```

5. El Oráculo (cualquier IA que lea SOUL.md + el contexto) responderá debajo en el mismo archivo.

Puedes volver a intentarlo tantas veces como quieras. Cada intento es un nuevo bloque.

Recuerda: el Oráculo no te dará la respuesta terminada. Te guiará para que tú la construyas.
